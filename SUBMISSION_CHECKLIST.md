# Submission checklist — starter status (NOT SUBMISSION READY)

Tick every box before you submit your repository link.

- [ ] Repository runs from a clean start: fresh virtual environment, `pip install -r requirements.txt`, then the commands in the README
- [ ] `requirements.txt` lists every package with a pinned version (`package==x.y.z`); Python version is stated in the README
- [ ] README has team name, members, chosen problem or project, summary, exact commands and expected runtime
- [ ] `WRITEUP.pdf` is 2-4 pages with Problem, Method, Results and Honest limits
- [ ] At least one figure shows the main result (in the write-up and in `figures/`)
- [ ] Results are checked against an exact or classical reference, with a fair classical baseline
- [ ] AI-use note names the tools, one specific thing the AI got wrong, and how you caught it
- [ ] README states what is simulated (noiseless / noise model / hardware) and which parts are shortcuts
- [ ] No API tokens, secrets or personal data in the repository or its git history
- [ ] (Optional bonus) Hardware run compared clearly with the simulator: backend, date, job ID
- [ ] Every team member can explain every circuit, formula and plot, and take questions if invited to present on Oct 18
- [ ] (Advised, not submitted) A short pitch deck is ready in case we are invited to present on Oct 18
- [ ] Ran `python scripts/check_submission.py <your repo path>` from the organisers' repo and fixed any failures
